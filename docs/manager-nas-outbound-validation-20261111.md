# NAS 回放与外发审核验证（2026-11-11）

## 已确认问题与修复

- 原始 MP4 的开放式 Range 允许七路同时读取余下整个文件。现在每次最多 4 MiB；显式范围、HEAD、完整 GET 和 TS 保持原语义。相同录制的自动预览路径探测复用两秒，减少重复 SMB 往返。
- 完整检查结束无条件暂停同一条正在播放的预览。现在保留用户播放/暂停选择，仅恢复的片段边界改变当前帧时暂停定位。
- 原外发接口仅查管理员目录，漏掉上传者个人/公司的真实星炬批次；平台已合并目录并保留上传绑定。生产认证转发和媒体路由现已启用。
- 外发长录制的分段曾被当成独立相机；现在按相机分组、分段选择，当前分段的票据并发最多四个，媒体错误时禁止提交，迟到响应不影响新任务，提交异常后核对平台最终状态。

## 目标 Windows 实测

使用实际编译的 1.8.6 Tauri/Rust 应用、用户提供的真实 SMB 目录及七路录制，未提交审核结论：

| 项目 | 实际结果 |
| --- | --- |
| 七路首帧 | 2.625 秒 |
| 跨完整检查连续播放 | 30 秒，七路均继续前进 |
| 暂停、拖动、续播 | 全部七路通过 |
| 观测期缓冲停顿/媒体错误/页面异常 | 0 / 0 / 0 |
| MP4 实际响应最大值 | 4,194,304 字节 |
| 采集时钟换算后的七路时差 | 播放约 19.7 ms，续播约 26.5 ms |

原始 MP4 的 currentTime 含各相机采集时序差异，同步核对使用真实 captureTimeline，不能只比较不同相机的原始秒数。目标主机为千兆有线、i5-13420H、16 GB 内存；这次观察没有证明主机配置不足，也不能据此排除其他负载下的 NAS/网络等待或承诺所有数据固定耗时。

## 外发审核完整隔离链路

实际组件、认证用户中心、HTTPS/HMAC 代理和平台账户服务共同运行，只写入临时合成数据：

- 七路乘八段与五路 MP4 均可播放，七路只载当前段并能切到第八段。
- 领取后分别提交有效和无效，三项预设及长期自定义原因可用。
- 派生 description 保留原字段，增加 `_outbound_review`；原上传 description 字节保持。
- 一条有效、一条无效，最终有效率 50%；待处理数据集也有统计字段。
- 两服务重启后原登录会话、审核结论及常用原因保持。
- 1440、960、390 像素视口无溢出和页面异常。

目标 Windows 测试、合成写入测试和生产只读测试是三组不同证据，不相互冒充。
