# 数据工作区快捷键（1.12.3）

顶栏键盘图标打开“快捷键设置”。点击功能右侧按键即可录入单键或组合键；Esc 取消录入。支持搜索、清除、单项恢复和全部恢复默认。当前工作区可能同时触发的重复按键或数字序列前缀会提示冲突，解决后才能保存。关闭、刷新等系统组合键不用于绑定。

设置在当前电脑保存，统一管理按用户中心与稳定账号隔离，离线模式独立保存。换账号立即切换设置，同账号其他窗口通过存储事件同步；不是跨电脑云同步。取消不应用草稿，保存失败保留原设置。打开设置、修改绑定和中英切换均不重挂载媒体。

| 功能 | 默认按键 | 适用范围 |
| --- | --- | --- |
| 上一条／下一条数据 | PageUp / PageDown | 本地、云端及外发审核；到边界停止，不提交审核 |
| 播放／暂停 | Space | 数据回放、校对、外发审核 |
| 上一帧／下一帧 | ← / → | 数据回放、校对、外发；校对边界聚焦时微调对应边界 |
| 上一片段／下一片段 | ↑ / ↓ | 校对动作片段；外发原始 MP4 分段 |
| 播放范围首尾 | Home / End | 数据、校对及外发 |
| 降速／加速 | − / = | 数据及外发当前已有速度档位 |
| 主相机静音切换 | M | 外发 |
| 裁剪起点／终点 | [ / ] | 普通数据裁剪 |
| 分割片段 | X | 本地／云端校对 |
| 审核通过 | Enter | 本地／云端校对，保留原有提交门禁 |
| 常用标签 1–80 | 对应数字序号 | 本地／云端校对，12 连续输入 1、2；可逐项改键 |

输入框、文本编辑、输入法组合、模态窗口及相应业务忙碌状态不触发工作区操作；校对标签库保留既有显式数字选择交互。数据导航沿用加载、自动保存与未保存门禁。外发按键没有“有效／异常／无效”提交映射，进入已审录制不会改写结论。

外发逐帧首次使用时才查询当前主相机帧时钟，按认证本机媒体路由读取 MP4 的视频轨 `mdhd`、`hdlr` 和 `stts`（含 B 帧时另核对 `ctts` 呈现顺序），跳过媒体正文，索引读取上限 1 MiB。只有确认为恒定正帧间隔时才移动；变帧率、未知或超预算索引明确提示暂不支持精确逐帧，不猜测 30 FPS，也不据此判视频损坏。暂停七路后在当前分段内同步定位，其他分段时长未知不阻挡当前正常段逐帧。原有源身份、Range、账号和释放校验保持，迟到结果不能改动新的录制。

回归入口：`pnpm test:shortcuts`、`pnpm test:proofreading`、`pnpm test:outbound-review` 及 `cargo test --manifest-path src-tauri/Cargo.toml --lib outbound_media`。快捷键浏览器回归使用合成视频与隔离账号，覆盖实际设置界面、账号／服务隔离、保存失败、三种尺寸、原默认多位标签、改键播放与只读导航；不向生产提交审核。目标 Windows 预览和正式发布状态按实际结果记录，不以浏览器夹具代替原生产数据验收。
