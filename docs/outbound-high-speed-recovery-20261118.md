# 高倍速缓冲恢复同步修正（1.11.9）

1.11.8实机同录制短时顺序对照：6/8倍出现部分镜头已缓冲约20–90秒但仍readyState=2并丢帧，不能只归因网络。另发现恢复中的镜头一旦canplay、共同储备仍不足时，原状态机继续让它以2倍走，其他镜头暂停，消耗新到数据并扩大时间差。该现象不能证明所有卡顿同因，也不能把非随机、冷热缓存不同的短时对照称为性能提升。

1.11.9在共同等待期间暂停已恢复的镜头；再次缺少解码数据的已暂停镜头以受限速率继续恢复，整组就绪且缓冲满足或储备等待到限后还原用户速率。保留原画质、七路显示、取消、连续播放不反复seek及原有1–3倍逻辑。单路解码恢复期间仍可能有短时差，不保证任意硬件6/8倍流畅。

定向回归覆盖先waiting、后canplay但缓冲不足、暂停镜头再次丢失readiness、共同储备完成后恢复8倍，以及用户暂停后不迟到开播。新Windows编译产物继续实测，测试证据保留在本机diagnostics。1.11.8旧窗口和登录保留，不代做任何生产审核结论。
