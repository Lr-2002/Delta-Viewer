# 外发连续回放与已审修改（1.11.7）

用户要求本版完成所有分段统一播放、更多倍速、固定七路及已审结论修改，并已授权验证后继续正式发布。旧 Windows 窗口、登录和审核状态保持，不代领代审生产数据。

同一录制固定显示 cam0、cam1、cam2、t265_left、t265_right、extension_left、extension_right，每相机保留一个 video 元素，切段复用同一播放器。真实额外相机也保留，不隐藏源数据。缺失位置保留播放器并显示源文件缺失，当前与后续分段的读取失败在对应卡片提示。已有相机可播放，但缺失／读取失败时不能提交结论。

所有可读分段共用一条连续时间轴，支持全局播放、暂停、跨段定位和段尾自动衔接；跨段保留倍速及主相机声音／显示方式。较短相机结束不截掉较长相机尾部。取消等待中的跨段播放不会在视频稍后就绪时意外开播。倍速为 0.25、0.5、0.75、1、1.25、1.5、1.75、2、2.5、3、4、6、8 倍。

总时长只使用原 MP4 的实际电影时钟和当前解码器报告，不假设固定五分钟。其他分段通过已授权随机本机媒体路由，以有界条件 Range 读取 moov/mvhd；跳过 mdat、不启动额外媒体解码器、不缓存媒体或绕过逐次来源／领取校验。时长未知明确提示，不编造完整时间轴；分段序号有断档时提示缺失区间时长未知。当前票据和后台时长请求共享四个未完成任务额度，快速切换撤销旧本机路由、释放迟到结果。

已审录制返回后可重新选有效／无效／异常，或修改已保存原因；原因对话框预选当前原因，仍支持保存常用原因。未改变的同一结论／原因不重复提交。成功修改留在当前录制，首次判断继续自动下一条；回执不明只读核对保存结果，不重放写入。领取身份、源就绪、版本冲突门禁保持。服务端现有 versioned decide 支持替换结论、重算独立计数并追加每次操作事件；派生描述更新，不改原媒体／描述。客户端不代做任何生产结论。

验证包括真实 MP4 七路浏览器播放、八段统一时间轴、跨段拖动／自动衔接／倍速、缺失和后续损坏、24次切换及资源释放、三结论互改／原因／回执不明、独立服务逻辑的统计／事件／描述副本／版本与身份冲突检查，以及原生范围读取测试。最终交付状态以本轮完整门禁、Windows 新预览、main CI 和三平台 Release 证据为准，不以本说明推定已发布。
