# 1.11.4 界面中英切换

English／中文按钮切换应用内置文案与日期显示，并用本机 `d1-manager-language-v1` 保存偏好。中文为默认；存储不可用时仍可在当前会话切换。React 使用订阅刷新显示，不把语言作为组件 key，不重挂载视频、表单或工作区，也不发起业务请求。

名称、账号、路径、原始动作描述、自定义标签和原因保持原文。内置审核原因只翻译按钮显示；审核、标签、任务和设备配置的请求值、固定状态码及格式 ID 不变。原生模态框内部也提供语言按钮，打开窗口不会使切换失效。

设备原页仍为受限 iframe：来源和当前 token 同时核对后才能接收语言消息，权限、允许路由、确认流程及原脚本保持。仅更新展示文本及提示属性，跳过输入、脚本、代码和身份字段；下拉框先保留原值再改变标签。切换不重新加载 iframe，后续原脚本更新的文案仍按当前语言显示。

英文词典为本地静态资源，没有运行时翻译服务、新增网络请求或翻译模型依赖。初稿使用 Argos Translate `translate-zh_en-1_9` 的 OPUS-MT 模型离线生成，关键业务和操作文案经人工校对。模型来源：<https://www.argosopentech.com/argospm/index/>；OPUS-MT 作者 Jörg Tiedemann 与 Santhosh Thottingal，模型许可证 CC BY 4.0，参见 <https://github.com/Helsinki-NLP/Opus-MT> 与 <https://creativecommons.org/licenses/by/4.0/>。模型和私有验证资料不随应用分发。

`pnpm test:i18n` 验证占位参数、稳定错误码、偏好保持、登录输入、原生弹窗、设备表单及 1440×920／960×680／390×844 的回放、检查、导出、批量页面；检查五路图像加载、控制台和横向溢出。外发专项另验证语言切换保留原生视频节点、播放位置、原因草稿和选择，不新增票据请求；合成有效／无效、回执核对与自动下一条保留。Windows 原生产物仍须验证；合成结果不代替真实生产审核。

用户已授权验证无误后发布。先打开独立预览并保留旧登录窗口，再按完整门禁、main CI、自动 annotated tag、三平台更新签名和制品校验流程发布；不手工 tag，不覆盖已有发布。
