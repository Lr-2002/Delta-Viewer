状态：Windows 预览候选，用户验收前不发布 Manager main/tag/Release。

## 实际阻塞与证据

平台 PR #159 已合并，main b7b7d7f215cb 的完整 CI 44019403381 通过。独立外发服务在 8798 运行原生 BOS 条件范围读取，原 FUSE 冷读被移出视频传输路径，其他业务服务及同事 overlay 保留。

修复源站读取后，Windows 1.11.0 的直接 HTTPS/HTTP2 实测仍需 32,786ms 才七路就绪，随后 11 秒仅播放约 3 秒。服务内部鉴权、定位和 BOS 上游通常只占数毫秒至数百毫秒，不能用源端小范围预检通过宣称视频已解决。

同一 Windows、同一组私有视频、相同普通证书校验下，七路各 1MiB：HTTP/1.1 共 1,575ms，HTTP/2 共 5,223ms。临时回环 HTTP/1.1 对照缩短了首屏，但旧播放器在 waiting 后暂停所有解码器；曾出现主相机 buffered 覆盖约 10 秒、当前位置 0.35 秒而 readyState 仍为 2 的停顿。另一次长片对照中，让缺数据解码器继续等待播放、健康相机暂停，可在约 2 秒七路就绪后完整播放约 29 秒片段；仍存在短暂停顿。临时对照不属于已编译候选的验收。

私有现场证据保存在本机 diagnostics/outbound-isolation-20261117，不提交真实视频、票据、账号令牌或截图。

## 候选实现

- `src-tauri/src/outbound_media.rs` 只接收用户中心已认证返回的固定 `https://114.111.19.219/api/platform/manager-outbound/media/<64hex>` 票据；前端不能提供 URL 或改变来源。
- 使用系统信任链和主机名/IP 校验、HTTPS、禁重定向、禁系统代理，强制 HTTP/1.1；不修改站点全局 HTTP2 或其他客户端。
- 为浏览器生成仅绑定 127.0.0.1 随机端口、256 位随机路由的本机地址。原票据不交给浏览器，不保存媒体或账号令牌到磁盘。
- 开放范围每次最多 4MiB，首块 1MiB、后续最多三块并行并按序发送。各块校验 206、范围、总长、Content-Length、实际正文长度；上游提供 ETag 时配对比较并发送 If-Match。显式范围、后缀范围、完整 GET、HEAD 保留语义。
- 最多 16 个活动本机连接，块缓冲有界；连接、读取与整体等待有限。请求中断会取消上游；本机账号/会话变化后取消活动读取、拒绝旧路由。平台仍独立逐次核对领取、来源与对象身份，没有公开 BOS URL 或绕过权限。
- `outbound-playback.ts` 在 waiting 时仅暂停健康相机，让缺数据的解码器保留播放意图；canplay 立即核对并恢复整组。主动暂停/离页仍停止全部相机，连续同步不反复 seek。
- 保留全部五/七路相机、主次布局、分段、真实缺失阻断、单批忙碌、回执核对和自动下一条。

## 验证与交付门槛

新增真实本机 HTTP 夹具覆盖七路并行、顺序及内容、HEAD、显式/后缀/尾部 Range、坏范围、短读、源标识变化、断连取消和退出后拒绝旧路由。浏览器回归保留五/七路、有效/无效、自动下一条、单批独立交互，并验证等待恢复时缺数据解码器仍能推进、健康相机等待。
