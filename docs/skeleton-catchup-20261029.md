# 骨架追赶显示试验（1.5.1）

用户明确要求在已知滤波延迟后试调骨架速度。本版保留现有平稳骨架，增加可回退的“原速同步 / 追赶 1.02、1.05、1.10×”。默认原速，不保存到下次数据或模型，不自动使用某条数据估算的延迟。

追赶从当前视频或片段起点按主镜头源时间计算：提前量为经过时间乘以倍率差，最多提前0.8秒，达到上限后同速。该值只影响骨架显示采样，不修改帧索引、源NPZ、视频、片段起止、人工结果或统计时间。播放器暂停和缓冲不继续追赶；暂停保留实验姿态，重复拖动到同一位置得到同一骨架，原速入口可立即回退。片段之外的暂停定位仍精确，片段内追赶不超过片段末尾；切换数据或模型恢复原速。

选择追赶时界面持续注明显示试验、上限及视频/骨架的不同帧号。这是人工比较工具，不能据此把骨架帧号当作源视频帧号做审核边界。时间定位仍使用原视频时间轴。短片段可能在追齐之前就结束；这优先保留完整片段边界。当前滤波响应延迟随动作变化，固定倍率和上限不会自动校准每一个动作，不能声称从根本消除算法延迟，也不以原始抖动骨架替代稳定处理结果。

本地验证覆盖原速像素回退、倍率上限、暂停与拖动重复性、片段边界、时间轴单位、新数据/模型重置和窄屏控件；完整构建和现有播放回归按正式门禁运行。目标Windows验证与实际发布结果保存在忽略的artifacts，发布前不宣称已验收。无NAS配置或业务服务改动，不自动推送更新提醒。
