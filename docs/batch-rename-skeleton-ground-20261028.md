# 1.4.2 批次实际更名与三维骨架地面参照

日期：2026-10-28。基线：正式 1.4.0（ed64812），保留此前原工作树。所有目录更名及审核写回验证只使用隔离 fixture，没有更名真实批次，没有重启用户中心、工作台或上传服务。

## 三维骨架原因与修复

此前 `fillJointPositions` 每帧减去该帧骨盆中心，抹除了根节点平移，包括真实垂直位移；地面网格只放在初次显示帧的最低点，打开位置不同导致参照不同，网格颜色又过暗。

现在整段使用固定起点和朝向，最多采样 256 帧的脚点低分位估计地面，显示地板、网格与骨盆地面投影圈。相机仅跟随水平移动，地面高度不随帧或跳转改变，不逐帧强行贴地。渲染不依赖旧的骨架包围球裁剪，避免走远后突然消失；释放地面和网格资源。界面显示“估计地面参照”。

地面不是实测标定；若源坐标没有世界平移，不能从局部姿态还原真实走动距离。源 NPZ、JSON 和采集文件不改动。

## 批次更名

入口位于已加载目录上方，弹出新名称确认窗口。实际更名同父目录下的单批文件夹，保留原采集日期前缀；拒绝根目录、分组、单条记录、云下载工作区、非法名称、同名覆盖及仅改变大小写。普通审核员更名共享批次前查询真实领取归属，不能改他人已领取批次。

共享批次复用 `layout.json`，普通外接盘使用父目录 `.delta-viewer-layout.json`。保留原有扩展字段。先写入带身份标记的 prepared 迁移意图、缓存本机别名，再调用系统原子 no-replace 更名；中断后只有旧路径缺失、目标身份标记匹配才恢复。最终映射写入失败时仍有可恢复意图并明确提示。磁盘写满导致意图无法落盘时不会执行更名。

旧路径、原领取 key、本机草稿、待写回的原 payload/事件 ID/时间保持。发布到源时解析新路径，不重写原提交。审核轨迹及回执使用本机缓存的历史路径保持统计身份，读取缓存不访问 NAS，失败保留未落盘保护。更名前卸载本窗口视频，成功后重载并恢复选中位置；其他程序占用导致系统更名失败时明确提示重试。

任务中心先验证原始服务器索引字节/hash/节点，再适配名称及路径，可读取尚未重新统计的旧分片。统计数量、统计时间保留服务器快照，未宣称实时全量核对。其他电脑需要当前版本兼容解析新路径；原始审核 JSON 内容不因更名改变。
