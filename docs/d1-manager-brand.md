# D1 Manager Brand Assets

The application icon and visible brand mark follow the supplied Delta logo identification specification. The source document and decrypted working material are not stored in this repository.

The standard ink mark is used for the application/window icon. The in-app mark follows the approved light-background treatment and preserves the source vector proportions. Generated PNG, ICO, ICNS, and SVG assets are checked into the application asset directories; the original PDF is not.

The app title displays `D1 Manager` with the current version. Preview-only wording belongs in delivery documentation, not in the visible app title or shortcut label. Formal package identity and updater asset names remain governed by the existing release contract.

Historical Windows preview images and binary fingerprints remain in private diagnostics. Platform release jobs are responsible for validating each shipped icon bundle.
