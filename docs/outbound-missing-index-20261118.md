## 客户端修复

1.11.6 在首次 GET 前读取最多 64 KiB 头部，再按块长度小范围跳读，跳过 mdat 正文寻找 moov；检查最多 64 个块，异常结构立即停止。查到 moov 仅代表索引存在，播放仍由实际解码决定；达到检查预算交回解码器，避免把少见容器误判为缺索引。文件末尾未找到 moov 时，不把数百 MiB 正文发送给 WebView2 继续无效加载。元数据仍核对 Range、长度、ETag 与源身份；每次实际源请求保留领取权限校验，不缓存视频或授权。

原生本机 media-status 只读返回固定错误码，严格绑定本进程随机回环地址及当前会话，无网络请求、不返回路径或凭据。界面分别提示索引缺失、容器结构不完整、网络中断／超时、凭证失效、服务繁忙／源站错误、源身份及响应完整性问题，支持中英切换。迟到诊断在切换、重试、播放器恢复后失效。

源文件保留原样。不自动重建索引、转码、替换源、重放审核或改变人工结论。修复缺索引文件需先由数据提供方核对本地原始录制是否已正常封装；若原件正常，可在既有校验流程下重新上传；若原件也缺索引，先用副本评估恢复能力并人工核对内容，不能凭空保证恢复完整。
