# D1 Manager 当前功能手册

本文随软件离线提供。图文教程和互动引导可切换中英文、搜索功能、退出后继续学习或重新开始。标注为 v1.11.6 的截图仅说明旧版控件位置，当前按钮和状态以正在运行的软件为准。

## 上手、账号与快捷键

离线模式适用于本机操作；联网工作区使用已配置用户中心的账号。退出前保存工作，临时断网按提示恢复，不反复创建账号。语言切换保留输入和当前工作。

数据工作区顶栏可以直接打开任务中心、选择数据目录、进入审核总览或检查更新。点击右上角头像、名称和账号，展开快捷键、文档、版本历史及账号操作；可修改显示名称的账号会在名称旁看到「修改」。离线模式也保留工作区菜单。需要排查时，从来源路径旁的诊断图标或错误提示打开操作错误历史。

「账号菜单 → 快捷键设置」可搜索、修改、清除和恢复绑定。设置按工作模式、用户中心和账号保存在当前电脑，不跨电脑同步。默认 PageUp/PageDown 直接切换数据、不提交审核；Space 播放/暂停，方向键逐帧或切片段，Home/End 定位首尾，减号/等号调速。冲突解决后保存；输入文字、弹窗和业务忙碌时避免触发工作区操作。

## 设备连接与配置

支持 Type-C、设备热点 AP、局域网 IP。选择连接并等待成功后，用下方设备管理、设备信息、检测排障入口打开对应页面。黄色提醒位于连接控件下方。

AP 能否查看运行信息取决于设备固件是否提供有效报告；只提供配网的固件会显示限制说明。Wi-Fi 配网提交可能断开热点。配置、升级前按界面提醒检查设备条件。

## 检测、日志与升级

运行设备检测取得真实状态、时间和告警。未知或过期不代表正常。现有本地诊断包包含健康观测与检测摘要，不代表已经取得设备原始日志。

软件已有的售后上传是独立且需主动确认的操作。新需求“D1 support-bundle 日志包保存到电脑”和“Agent 问答”仍在接入准备阶段，本版本未提供，不能以旧的售后上传代替本地接收。

设备应用升级与 Manager 软件更新是两个入口。设备升级使用所连接设备的 SSH，三种连接方式均按实际 IP 工作；需停止录制、自检、压力测试并保持供电、连接。按设备实际电压、温度与运行条件判断，低电量先充电。检查提示已是最新版本时无需重复安装；超时应分清 OTA 源站与设备连接原因。发送或下载完成不等于安装成功，以最终运行版本与结果为准。

## 数据载入与回放

选择 SD 卡、外接硬盘或 NAS 数据目录后直接读取；加载路径、列表状态和错误历史可核对。单击选择，双击或键盘打开录制；不需要先复制整条数据。完整检查和导出校验仍由相应操作执行。

相机按真实源展示，缺失位置有占位，不会补造镜头。支持主相机铺满/完整画面、全屏、拖动、暂停逐帧、帧率及清晰度选择。本地提供 0.25×、0.5×、1×、2×、3×、4×、6×、8×；外发提供 0.25×、0.5×、0.75×、1×、1.25×、1.5×、1.75×、2×、2.5×、3×、4×、6×、8×。

可选“高速浏览”默认关闭，在 4× 及以上抽帧无声浏览，保持原清晰度和七路。暂停后用逐帧精查，关闭开关恢复普通模式。读取和解码能力会影响实际速度；出现缓冲请等待恢复或按具体错误重试，不能由已选 8× 推断一定达到 8×。

“本地流畅播放”仅在主动选择后准备本机缓存；它与普通直接读取不同。取消、完成和清理状态以实际提示为准，不删除源采集数据。

## 校对、标注与特殊标签

按机标来源和真实时间轴校对动作边界，可分割、调整、补充标签与原因。特殊标签可自定义并保存常用项沿用；名称内容保留原文，语言切换不改提交值。

通过/不通过属于真实审核写入。未保存时先处理草稿，确认回执后再继续。快捷键切换数据不会代替提交审核。帧率未知时不猜测逐帧精度。

## 检查与导出

检查页区分错误、警告与通过，可定位问题并导出报告。交互抽检不是全量解码证明。导出依照当前格式和后端检查支持 MCAP、HDF5、LeRobot；阻断错误需处理后再导出，输出目录由用户选择。

## 本地任务与写回

任务中心读取目录与任务统计，按权限领取、打开、恢复审核。后台同步时保留已显示列表。打开 NAS 批次时，进度显示已扫描的目录数量。NAS 断连产生的本机待写回与服务器已确认进度不同；恢复后核对写回结果，不能把待写状态当作最终成功。

## 云端 QC

使用已配置且本人有权访问的批次。按批次状态查看抽检、领取、回放及结论，保留原始视频和平台权限。下载或刷新失败时依据具体错误处理，不新建重复任务来重试同一审核。

## 外发审核

任务按交付平台配置的星矩公司真实归属同步。领取并打开后进入主工作区，每批独立显示忙碌状态。七路固定位置展示，主相机较大；多个 MP4 分段组成连续时间轴，自动衔接，也可跨段拖动。切换录制会释放旧视频读取和解码资源。

播放长时间没有进展时会从当前进度自动重连一次；同一位置仍停滞时可手动点「重连视频」。缺片提示列出分段和相机，点击可跳到对应分段；读取失败另行显示。有效要求所有视频齐全并就绪。异常和无效可在视频未就绪时按实际证据填写原因；缓冲超时本身不代表文件损坏。异常与无效各有独立常用原因库，支持添加、排序、删除，删除常用项不改历史结论。服务不支持第三种结论时按提示处理。

第一次结论保存成功后自动进入下一条待审；最后一条确认保存后，审核页和任务列表会显示绿色「审核完成」。完成表示每条都有结论，与合格率无关，不会自动释放批次。本人仍可重新打开修改，修改会更新统计并停留当前记录。回执不明时软件先只读核对，不连续点击重复提交。暂时服务中断保留列表，恢复后继续；权限过期、源缺失与网络故障按不同提示处理。

## 审核监管与账号管理

有管理权限的账号进入管理模式后默认看到「审核账号」；「NAS 写回」单独展示下发与回执。右上角账号菜单可打开外部审核工作台、文档，或按权限返回测试模式。账号状态、更新提醒和写回等操作影响真实账号或共享数据，使用前核对目标和范围。

## 文字勘误

搜索原词、预览目标和范围后再应用修正，查看修改历史或撤销。自动匹配结果需要人工确认，用户名称、路径及业务原文不会因界面切换语言而改写。

## 版本与更新

在软件内打开“版本与更新”，选择自动、公司内网或 GitHub 线路并检查更新。查看正式/候选来源、说明及当前状态，下载校验后由用户主动确认重启安装，先保存工作。

手动“下载安装包”与自动更新独立：可选择已提供的平台包和保存目录，完成后打开位置自行安装；预览包可能仅提供已经构建的平台。历史包在版本历史中下载或回退。预览包可下载不表示正式发布或所有性能问题已解决。


### 骨架标注来源

在“骨架片段”的“骨架标注来源”中选择人工结果或其他骨架标注文件。来源文件名必须包含 `skeleton` 并以 `.json` 结尾，扫描范围为当前录制根目录和 `.session_meta`；同名文件以路径区分。纯骨架腾讯结果为 `skeleton.description.tencent-custom.v1.json`。选择来源会载入该文件的片段，可按现有流程增加、删除、修改及调整边界。

所有骨架人工编辑统一保存到录制根目录 `skeleton.description.json`。来源文件保留原样；骨架保存不提交审核结论、不更改动作标注或 QC。默认打开人工结果；切换到其他机标来源时载入对应机标，不自动将另一来源的人工片段套入。待保存、保存失败或共享文件已变化时，先处理保存或重新读取，避免覆盖其他人的工作。
