# 快速开始

## 1. 选择工作模式

首次启动先选择工作模式：

- **统一管理模式**：导入管理员提供的用户中心配置，再使用管理员创建的账号登录。账号只用于记录“这条数据由谁处理”；账号创建和密码重置由用户中心管理员完成。服务部署步骤见[用户中心部署](User-Center-Deployment)。
- **离线模式**：不导入配置、不登录账号、不请求用户中心，也不检查自动更新，直接使用本机扫描、检查、回放、标注和导出。标注内部使用固定的离线本机 provenance 标记，但界面不显示账号或处理人。

切换工作模式会清空当前载入的 episode、检查和标注状态；统一管理模式切换后需要重新登录。

## 2. 选择 SD 卡

点击顶部的“选择 SD 卡”，选择操作系统已经挂载的卡根目录或本地测试目录。应用会立即扫描直接子目录中的全部 session，并直接从源路径只读加载第一条记录。不会出现本地目标目录选择框，也不会自动复制 session。

源卡只读。应用不会在源卡上创建、重命名、修改或删除内容。检查、回放和导出期间必须保持源卷挂载并连接稳定。

## 3. 等待读取和检查

首条 session 会自动进行结构与状态全量检查，并在五路图像的固定百分位执行 JPEG 解码抽检。进度条会显示阶段、当前路径、文件进度以及耗时。正常界面不调用导入器，也不会在 app-local-data 中生成一份源数据副本。

交互抽检不等于全量 JPEG 验证；具体覆盖范围见[数据检查](Data-Validation)。源卡拔出或挂载中断后，当前数据将无法继续回放或导出，重新挂载后再选择目录即可。

## 4. 选择其他 session

左侧列表只用于选择 session。单击更新选中项；双击，或聚焦后按 Enter/空格，才进入正常回放：

- 已经加载的 session 直接进入回放。
- 尚未加载的 session 会从源路径读取并检查后进入回放；读取失败的 session 可再次双击或按 Enter/空格重试，错误会保存在顶栏的操作错误历史。

## 5. 检查、标注与导出

先查看[数据检查](Data-Validation)结果，再到回放页确认五路画面和彩色状态曲线。可以选择已有任务，或只输入任务名称创建新任务；任务描述可编辑，轨迹码只读并在保存时由系统自动编号。之后可在导出页选择 MCAP、HDF5 或 LeRobot v2.1。

需要处理多条已标注数据时，打开“批量”页，勾选源仍可用的轨迹，选择一种格式和一个目标目录。应用会顺序重新检查并完整导出每条 episode；单条失败不会中断后续条目。标注不包含数据副本，因此原始源卷必须保持挂载且内容不能变化。
