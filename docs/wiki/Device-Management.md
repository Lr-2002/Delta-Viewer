# 设备管理与诊断

1.6.5 起本地预览使用真实 D1 健康报告，已移除设备模拟功能。1.6.3 已正式发布，当前 1.8.2 为待发布候选。当前支持 Windows、Linux 上的受支持 USB 网络链路，macOS 自动发现尚未开放。设备信息顶部概览按真实报告状态显示绿/黄/红，过期或未知状态为蓝；电压和温度不使用应用自设阈值。登录时密码默认隐藏，可通过密码框旁的眼睛按钮临时显示。

首页集中展示连接方式和当前状态，检测、日志和数据区通过导航进入，不再重复放置功能卡片。父级分为“设备管理区”和“数据工作区”；设备页的子导航为首页、设备信息、检测排障、日志与支持。选择SD卡/目录、数据路径与错误历史属于数据工作区，不在设备页展示。

## 连接 D1

将已开机的 D1 用数据线连接电脑，在“设备信息”查看设备标识、DOHC 应用版本、板端版本、相机、存储、电压、温度和设备告警。状态会自动刷新；多个连接时先选择设备。设备身份来自设备自报，尚未提供配对认证。

若只看到 USB 连接但无法读取报告，检查数据线/端口和设备状态服务；不要把此情况理解为设备硬件损坏。设备信息显示连接 IP（Type-C 时为 USB 地址）。它与设备自查的联网 IP 可能不同；当前联网 IP 尚未取得时显示“暂未获取”，不以电脑地址或 USB 地址替代。拔出设备后当前信息会清除，历史检测仍带原观测时间。

无线连接分为两种：

- **设备热点（AP）**：设备未在采集时长按录制键，听到进入AP的语音后，在电脑Wi-Fi中连接标签对应的`Delta-D1-***`，使用设备默认密码。选择“设备热点（AP）”，Windows会显示可用Wi-Fi并优先推荐D1热点；核对标签后点击“连接热点并打开”。默认密码自动使用，必要时可选择“手动输入密码”。软件从实际连接读取热点网关并展示设备原生页面，当前实测为 `192.168.4.1`；该热点无需能上互联网。只有你点击连接时才切换电脑Wi-Fi，使用临时连接，不保存普通配置密码。其他平台请先通过系统Wi-Fi连接热点。
- **局域网IP**：先通过AP配网并确认设备联网，长按录制键后接短按，等待语音播报本机IP；让电脑与设备网络可达，在“局域网IP”输入播报地址并连接，直接在软件内打开设备原生状态页；支持经路由可达的私有网络。请使用设备联网后的实际地址，不能拿配网热点地址或电脑USB地址替代。

上述操作与按键顺序来自[设备操作手册](https://scnrtmmwx9sj.feishu.cn/docx/N5tJd9hUTo0HTvxBCaxcUaWLnng)第03与07节；以设备语音确认结果。软件不代执行设备按键。原生页面提供返回、刷新和已确认的配置操作；配网与配置保存会先弹出确认，相机配置可能中断采集，热点配网成功会关闭原热点。设备升级仍禁用，未知功能不转发。AP仅使用Wi-Fi网卡，避免同地址USB误连；多个匹配网卡时选择连接。AP只从Wi-Fi实际同网段网关读取；原生页面与健康报告均固定路径，不扫描、不接受域名、URL、端口或自定义路径。Wi-Fi列表约每2秒核对实际关联，百分比表示信号质量；读取失败不保留旧连接标记。当前热点可展示配网页面，但 `/health` 没有健康报告，不能据此称完整热点诊断通过。

D1 唯一 Type-C 口平时连接扩展双目相机。该口连接电脑时，缺失的扩展双目相机标为未执行，说明诊断占用，不算通过或硬件故障；设备自身仍可能亮红灯。在热点已支持健康报告或设备已联网的前提下，接回镜头后通过无线连接完整复检，AP 模式不豁免相机。其他相机、供电和存储的异常继续显示。

配置页面读取有超时提示，可往返运行配置；保存失败且结果未确认时，先重新读取核对，避免重复提交。配网提交后显示等待动效，热点消失或超时不代表成功；当前设备没有结果/IP查询接口，只能依据重新连接热点后的设备失败提示，或输入新IP核对联网状态，自动实时成功确认尚待设备接口。

## 检测与复检

在“检测排障”点击“运行设备检测”。它只读取设备当前健康报告，不启动录制、长时自检、重启或修改设备。设备信息与检测卡片使用和原生状态页同源的设备报告，中文展示相机、存储、采集写入、状态灯及已有自检结果；观测时间、版本和原始告警可追溯。缺少字段、报告过期或断连显示无法判断，已有历史自检不冒充本次执行。处理后重新检测。

正常、异常、无法判断、不支持、未执行是不同结果。相机恢复中、断连、超时、解析失败不能说明硬件损坏；未运行的设备长时自检显示未执行。设备健康报告本身异常时仍展示具体原因，不用网络错误遮住故障信息。

## 本地诊断包

检测后进入“日志与支持”，先预览文件和隐私范围，再选择本机目录导出。包包含 `manifest.json`、`diagnostics.json`，取得有效观测时另有 `health.json`。它记录本次真实设备观测、版本、时间、结果和 SHA-256；不含原始设备日志、人员名称、任务、账号或审核队列。

已有包不会被覆盖。包不会自动上传，分享由用户自行决定。“上传诊断包”按钮已预留，目前显示“上传服务待接入”并禁用，等待正式总服务后端接口；尚不能上传。原始设备日志收集尚未开放；浏览器页面不能检测设备或导出包。

## 应用升级

设备 DOHC 应用升级仍显示“等待升级服务接入”，尚无可执行升级功能。它与“版本与更新”中的 D1 Manager 自身更新独立，应用更新验签保持原流程。

## 原数据工作区

回放、骨架、标注/修订/草稿、审核、用户中心、任务中心、NAS 写回、检查和导出完整保留；骨架使用原数据目录，已移除模型库切换与筛选入口。切离数据区前先保存草稿/审核记录并暂停播放与快捷键；失败仍留在当前会话。设备区操作不计数据审核活动或有效时长。
