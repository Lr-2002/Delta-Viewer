# 设备管理与诊断

本页适用于 D1 Manager 1.6.3 本地候选，尚未发布。当前真实设备连接、自检、日志读取和固件更新暂未开放；所有可运行的设备场景均为用户主动开启的本地模拟，不连接真实 D1。

## 导航与原有数据功能

首页、设备管理、检测排障、日志与支持和数据工作区是五个主入口。原 Viewer 的回放、骨架、片段编辑、标注、审核、用户中心、任务中心、NAS 写回、检查、批量导出和应用更新全部保留。

从数据工作区切到设备区域时，应用先保存草稿和审核操作记录，再暂停播放和编辑快捷键；保存失败会留在当前页面。切回可继续使用已载入数据与草稿。管理员保留管理入口和权限，导航不会获得新的数据审核权限。

## 本地模拟

1. 在首页或设备页面选择“体验本地模拟”。页面会持续显示“本地模拟 · 未连接真实设备”。
2. 在检测排障中选择整体正常、单项异常、部分能力不支持、设备离线、超时、断连或响应无法解析的合成场景，运行检测；可以取消后重新运行。
3. 查看每项观测证据、时间、适用版本与建议。正常、异常、无法判断、不支持和未执行是不同结果；超时、断连和解析失败不能说明硬件损坏。
4. 模拟的身份与固件版本只适用于合成场景，不代表实际设备信息。模拟活动不计入数据审核活动或有效时长。

## 本地诊断包

桌面客户端完成模拟检测后，在日志与支持中选择本次运行内的时间范围，先预览文件与摘要，再选择本机目录导出。浏览器演示不提供文件系统导出。

包是一个目录，包含 `manifest.json`、`diagnostics.json` 与 `logs/simulation.jsonl`，标有模拟来源、范围、版本和文件 SHA-256。仅有模拟摘要和合成日志，过滤合成凭据消息，不收集账号、审核队列、个人源文件或真实设备日志。已存在的诊断包不会被覆盖；当前没有上传入口，分享由用户自行决定。

## 设备固件更新

当前显示“等待接口接入”，没有可执行的升级功能，也不会探测或访问预留服务。真实接口与设备升级另行接入。现有“版本与更新”继续负责 D1 Manager 应用更新，其来源限制与验签不变。
