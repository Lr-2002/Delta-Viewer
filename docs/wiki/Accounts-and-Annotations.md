# 账号与数据标注

## 本地账号

账号保存在当前电脑的 DOHC Viewer 应用数据目录。密码只保存 Argon2id 哈希和随机盐，登录会话在应用退出后失效。账号不连接服务器，不提供角色权限或跨机器同步。

拥有当前操作系统用户文件权限的人仍可能读取本地报告和标注；本地账号不是磁盘加密或操作系统隔离机制。

## Episode 标注

回放页顶部为当前 episode 选择任务。可以从目录中选择已有任务，也可以点击新增按钮并只输入任务名称来创建本地任务。系统会生成稳定的任务 ID、编码前缀和默认描述；默认描述可以针对当前 episode 继续编辑。选择内置 `close_oven` 时，默认描述为“关闭烤箱门，并确认烤箱门完全闭合。”。

轨迹码采用 `{prefix}-{NNN}`：`close_oven` 的前缀是 `oven`，因此依次分配 `oven-001`、`oven-002`；例如新建“整理餐具”任务时会得到 `整理餐具-001`。轨迹码字段只读，界面只显示预览，真正编号由 Rust 后端在保存时原子分配。在同一应用数据目录中，一个编号不会分给两个不同 episode；同一 episode 继续编辑相同任务时沿用原编号。

保存标注时会记录：

- 规范化 episode 路径和数据指纹。
- 任务 ID、显示名和可编辑描述。
- 轨迹码。
- 当前登录账号和显示名。
- 修订号和保存时间。

每次保存追加一个修订，不覆盖处理历史。任务定义保存在 `appLocalData/tasks`，轨迹占号和标注分别保存在 `appLocalData/trajectory-codes` 与 `appLocalData/annotations`；这些内容不写入源卡。三个导出 adapter 会继承同一任务、轨迹码和处理人信息。
