# 1.12.5 高速浏览和独立原因弹窗

用户接受减少高倍速展示帧数。4×及以上可选择高速浏览，默认关闭：七路只定位最新采样，等待本轮完成再推进，无额外解码器、转码、画质降低、媒体副本或生产写入，采样无声。间隔至少250ms、单轮时间增量最多500ms×倍速，慢链路不追赶积压。暂停后仍可精确逐帧；本地按真实采集时钟／分段映射，外发按测量时长连续衔接。普通1–3倍及未启用模式沿用原生连续播放。

同一Windows真实五分钟七路（4K主路）独立控制器对照：8倍约8.29秒推进39.25秒，采样约8.09秒推进59.75秒，采样镜头时差小于0.000002秒，无媒体错误；6倍约8.12秒推进48.08秒。此证据为诊断程序，不是1.12.5编译产物、外发网络或所有硬件的保证。当前用户打开的是本地样本，不冒充本人领取外发长录制。

原因使用与不通过弹窗一致的两列按钮、其他原因、添加与调整顺序，管理模式删除自定义项。异常与无效各自标题、内置内容、远端常用库和本机账号／类别排序独立；旧无分类词仍只属于无效。删除明确携带category和remove:true，后端仅修改对应建议库，历史结论与同文另一类不动。网络失败保留选项并在弹窗显示；排序持久失败不应用。其他原因仍显式保存为该类常用项后选择，保留既有审核原因契约。

验证：新增单元覆盖七路采样屏障、无积压、暂停／逐帧、切模式／低速和结尾一次完成；真实视频浏览器验证本地跨段与精确暂停、外发连续分段；原因验证独立词库、添加删除失败／成功、排序重开与历史结论不变。最终完整门禁、新Windows预览、相关服务上线和软件内更新以实际结果为准。
