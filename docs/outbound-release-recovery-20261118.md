# 外发审核完整版本发布恢复（1.12.0）

1.11.9 的 Windows 预览和本地完整门禁通过，但 main CI 44269945446 未通过，没有 tag 或 Release。用户已明确授权保留失败历史，以新版本 1.12.0 恢复完整自动发布。

## 阻塞与修正

两轮临时构建机从 `us-east-2.ec2.archive.ubuntu.com` 下载 Ubuntu 依赖过慢，超过 8 分钟。既有源配置仅识别 Azure、主源及安全源，漏掉 EC2 区域镜像；新增精确官方主机匹配，保留其他软件源、suite、组件和签名验证。回归覆盖两种区域地址、第三方源、伪造后缀及重复执行。新回归在旧脚本上失败，在修正后通过。

另外两轮在 `seven_cameras_ranges_integrity_logout_and_disconnect` 的 `response.bytes()` 超时。测试先取得七个响应头，再顺序读正文并逐字节核对；扩大范围后总计 112 MiB，前一路验证会消耗后续响应相同的三秒总截止时间。夹具还为各请求重复生成模式字节，使繁忙的 debug 构建机承担额外 CPU 工作。

修正于请求前生成只读模式源，七路正文并发读完后再逐字节核对。仍使用三秒 client 截止，不调整生产读取期限，不跳过完整范围、错误范围、短正文、源变化、分块并行屏障、退出或断连取消断言。独立修复副本在两个 CPU 限制下全部原生测试 370 通过、0 失败、17 忽略；七路单项 1.80 秒。这些本地结果不替代新版本的完整门禁和 GitHub CI。
