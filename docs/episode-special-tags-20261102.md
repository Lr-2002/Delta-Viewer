# 1.5.2 整条数据特殊标签（2026-11-02）

## 功能与保存范围

- 回放下方提供特殊标签，可选整条数据或本条实际接入的相机；添加、编辑和删除多个说明。
- 最多20条，每条1–200字，拒绝空白、控制字符、重复相机/说明组合。已有相机未接入时仍保留其名称。
- 使用现有人工作业草稿/持久待写队列，按账号及来源隔离。未审核不修改共享 JSON；明确提交通过或不通过后，将 `special_tags` 数组写入当前人工结果 JSON。每项仅含 `camera`（空串表示整条数据）和 `description`；清空时移除字段。
- 不通过只发布标签和结论，不发布未获通过的动作片段改动。原机标及视频保持只读；`_human_review` 仍只保留 status/reviewer/reviewedAt，技术记录另存。骨架描述无审核逻辑，保持原流程。
- NAS不可写时在本机保留整个请求，恢复写回时仍核对来源/共享结果/版本冲突。旧客户端省略标签不清空已有共享/本机标签；批量不通过保留共享标签。重新编辑批量待写结论时复制原共享标签。
- 用户中心只接收通用“修改数据特殊标签”交互，不接收标签说明或相机名。
