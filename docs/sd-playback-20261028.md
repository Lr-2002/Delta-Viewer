# 1.3.9-rc.cloudqc.8：SD 长记录回放优化

基线 ff991f8；仅独立云 QC 候选，不改变 1.3.8 审核业务规则，不更新服务端，不写源媒体。诊断证据在 /home/descfly/reports/f-drive-viewer-20261028/report.md。

- 新布局状态文件超过 8 MiB 时，读取首尾各最多 128 KiB 的实际状态，先返回带 statesPartial 的只读视频预览；完整检查仍在原任务中执行，完整状态成功返回后才启用编辑器，抽样不能冒充完整 telemetry。没有首尾有效状态则沿用完整路径。
- 状态快照一次读取/解析，复用于扫描、校验与载入；按规范路径、大小、mtime 匹配，最多四目录、合计 250,000 状态，异常/取消/读取中变化不缓存。此缓存仅内存，不新增源目录文件；不移除状态错误或指纹检查。
- MP4 CFR 时钟只读有界容器 header/mdhd/stts，跳过 mdat；VFR/异常继续原 FFmpeg 探测。
- times/<stream>.json 校验 schema、CLOCK_BOOTTIME、unit、流名、帧数与严格递增，最多 16 MiB/500,000 帧；转换到规范状态批次时间轴。原生暂停/拖动、连续主时钟、分段索引、逐帧回退使用同一映射，并按每段真实跨度调整播放速率。时间文件缺失保持旧映射；存在但无效明确提示“时间轴回退”。
- 任何原生相机缺缓存均触发共享暂停，恢复前对齐当前帧，播放余量 0.75 秒；其他相机显示“等待其他相机”。暂停 metadata 预载减少七路无界争用。

限制：首次完整检查仍须至少读取一遍状态文件；这里没有自动转码/复制原视频。物理 SD 链路若持续只有 0.67 MiB/s，软件不能供给约 8.2 MB/s 的七路原片；会协调缓冲，不承诺全程无等待。不同 USB/卡对照尚待用户硬件条件。元数据缓存不能识别外部在保持大小/mtime 不变时故意改写文件，这是既有源指纹元数据模型的限制。
