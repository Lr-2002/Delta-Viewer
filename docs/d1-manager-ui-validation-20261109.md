# D1 Manager UI Validation

The 1.6.8–1.7.0 preview iterations tightened the device workspace layout, separated device and data-workspace navigation, clarified connection and diagnostic states, and kept existing Viewer workflows reachable. Known device values are translated for display while raw evidence remains available in details and the local diagnostic export.

The Type-C camera-port limitation is represented as a connection constraint, not a successful camera test. Missing, stale, or disconnected observations remain unknown. Diagnostic-package upload stays disabled until the service endpoint and contract are supplied.

Browser viewport checks covered desktop and narrow layouts. AP hardware behavior, LAN reachability, macOS/Ubuntu installation, and upgrade-over-existing-user-data were not all established by those UI checks. Private screenshots and device reports remain outside this repository.
