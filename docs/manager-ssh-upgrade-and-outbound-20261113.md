# 1.10.0 SSH 升级、售后日志与外发响应验证

日期：2026-11-13。用户要求 Type-C、热点和局域网 IP 均按实际设备地址使用 root SSH 升级，替代原 AP 上传流程。保留源媒体、账号、队列、审核结论、草稿及旧窗口。

## 原失败与新流程

原 AP 升级的五文件上传已完成，但设备 1.1.1 返回 `OTA_TRUST_ROOT_MISSING`，缺少 `/etc/dohc/ota-release.pub`，尚未进入安装。这是设备旧 updater 的验签门禁；下载接口可达不能替代设备安装条件。新版按用户要求改用 SSH，不再向 `/ota/upload/v1/session` 传包，不继续索要发布私钥、公钥或采集目录。

1. 从固定 4174 Factory 通道读取原始清单、配对签名和发布资源，核对大小、SHA-256 与版本一致性。若配置受信公钥则验签；当前未配置，只声明摘要核对。
2. Type-C 使用所选 USB 网卡的实际设备网关，热点使用实际 Wi-Fi 设备地址，局域网使用输入的私网 IP。统一使用 SSH 22 和用户指定的默认设备账号。网页读取失败不阻止 SSH 状态查询。
3. SSH 读取完整 CID、设备 UUID 和运行版本，本机按 CID 固定主机指纹，后续变化拒绝。固定执行器不接受前端 shell、密码或任意下载地址。
4. 优先设备下载已锁定版本的工件路径；设备无外网时，经 SSH 发送 Manager 已核对的同一 `.deb`。设备再次核对完整大小和摘要，传输失败不进入安装。
5. 安装前检查空闲状态、writer 队列、自检／压力测试、健康报告时效、必需组件、温度、供电和空间。沿用原 updater 的仅 SD 存储阻断例外；默认电压至少 7.3V、温度低于 75℃，以设备配置为准。
6. 全局锁和独立 systemd 单元防止重复安装，连接中断不会终止已启动任务。核对 `d1-system` 包名、版本和架构，仅提取包内两个已知依赖，再由 Debian 包内安装器执行服务切换、健康检查和自身失败恢复。
7. 核对实际运行版本及 updater、monitor、camera 服务后才报告成功。工作进程异常消失为 UNKNOWN，阻止再次安装，须先核对日志。

SSH 流程不声称具备原 AP OTA 的发布者验签、防回退或自动回滚。D1 Manager 自身更新的签名校验不变。本次未对实体 D1 执行安装或安装后健康窗口验收。

## 日志与检测

每次用户确认产生随机操作 ID，先保存本机记录；身份或认证失败也保留失败事件。记录按服务及账号隔离持久化，界面读取最近 100 次，每次保留最近 200 条脱敏事件。远端安装日志位于 `/var/lib/dohc-manager-upgrade/<operation>/install.log`。

升级日志直接用 SSH 取得的完整 CID 关联现有 Device 档案，无需选择采集目录。用户预览并主动上传；冻结报告内容、报告 ID 和幂等键，超时重试不新建报告。记录变化使旧上传回执失效，迟到回执不能把新日志标成已上传。本机保存回执失败不掩盖服务端已接收。

普通检测上传修正 `identity_verified` 字段误挡，仍核对真实设备 UUID 与同设备采集目录的完整 CID；不以 IP、设备 UUID 或 CID 尾号替代 CID，不自动登记设备。“运行设备检测”操作位于检测页顶部。本次未向生产诊断接口 POST。

## 外发卡顿证据与修改

生产只读样本 14 批、198 条录制，185 条七路、12 条五路、1 条单路。列表耗时 4.735／6.053 秒；首 MiB 响应头等待 5.19／8.66 秒，正文约 0.24／0.23 秒。底层文件读取样本约 0.4 秒。部分 MP4 索引位于文件尾，会使浏览器多次 Range 等待累计。

前端按实际相机名称和真实分段号显示全部相机，缺路保留位置并阻止审核；主相机占更大区域并提供声音。录制队列使用 memo，避免播放时钟每次更新重绘整队列。轻量列表、单批详情及紧凑审核回执减少传输与重复构造；只有明确旧协议错误才回退，不在超时后自动重发写操作。

平台修复在 [Delta-jiaofu PR #128](https://github.com/Delta-data-Delivery/Delta-jiaofu/pull/128)：媒体请求跳过无关就绪刷新、单请求仅取一次上传快照、只投影目标录制；列表不等待逐批 description 修复，审核结论只写当前录制，响应增加 Server-Timing。仍逐请求核对领取人和源绑定，不跨请求缓存权限。全局事务等待尚未量化，不能归为已证实的耗时比例。

平台 PR 未部署，须由同事验收合并；前端兼容旧协议。不能用本地夹具通过宣称现场首屏已加速，部署后仍需对同条真实录制复测。
