# D1 Manager 1.9.6 验证记录

日期：2026-11-12。基于正式 1.9.5，保留应用身份、账号、审核队列、草稿及原有窗口。

## 用户可见变化

- 特殊标签可“存为常用”，按账号本机持久保存，点击复用说明并为当前数据重新选择相机；移除常用项不改已有审核结果，本地／云编辑器共用。
- 打开数据不自动运行全量检查，也不二次加载。完整状态、骨架、保存片段和草稿恢复保留；检查页明确显示“未检查”，用户主动运行，导出校验仍由后端执行。
- 外发领取只在当前批次显示忙碌，直接使用领取回执进入主工作区，不再重复读取全部批次。只有主相机驱动连续播放时钟，保留五／七路、多分段、有效／无效和常用原因。
- 黄色操作说明放在完整连接操作下方；AP 包括热点列表和连接按钮。仅提供配网／OTA 的热点明确为配置模式，完整设备状态以实际接口能力为准。
- 设备网页升级入口进入宿主升级面板。下载固定 Factory 发布的五文件，核对原文、ETag 配对、大小和摘要，按实际 deb／tar 工件格式上传；中断后查询同一会话并跳过已接收块，提交结果不明不重复安装。
- 日志预览冻结本次报告和幂等键，加入后端持有的真实检测与告警；选择同一设备采集目录，从 session.json 读取完整 CID，关联 Device 档案。重试不重新采集，未知项目不算正常。

## 验证范围

本地完整门禁包含前端构建、版本一致性、Rust 格式／Clippy／单元测试及 Tauri debug 构建。浏览器回归覆盖打开零自动检查、手动检查取消／重试、导出对话恢复、草稿与片段播放、外发领取及多路持续播放、中文设备页面与配置交互。

本地结果：Rust 主测试 352 通过、17 项环境／私有样例测试忽略；校对与常用标签 53／53、外发 2／2、设备与 OTA／日志 UI 18／18、会话激活 3／3、导出对话恢复 1／1，操作归属浏览器 smoke 通过。常用标签包含重启、账号隔离、跨录制、存储失败重试及不修改历史结果的验证。Demo flow 11 通过、15 项既有场景忽略；Wiki 16 页链接核对通过。全量门禁报告与具体浏览器日志保留在本机证据目录，未作为产品数据提交。

原生 HTTP 隔离回归使用 loopback 测试服务，覆盖 generation 配对签名资源、真实五文件协议、上传中断与块续传、complete 回执、旧操作状态隔离；诊断覆盖同一请求体／幂等键重试、201 回执、错误设备身份拒绝及未知检测保留。它们不会向生产服务提交测试数据。

## 实机与信任边界

- 4174 Factory 源站只读可达；版本随通道变化，不硬编码文档中的旧版本号。
- 当前设备在目标 Windows 的 AP／局域网只读复查均超时；此前 AP 曾返回有效的 OTA IDLE 状态，局域网旧版设备未提供 OTA 路由。接口缺失或设备失联会显示不可用，不能据此声称已完成真实安装。
- 本轮未执行设备 OTA 安装、安装后健康窗口或回滚；未向生产 Device 接口 POST 测试报告。当前设备的完整 CID 尚未取得，不能使用另一台设备的会话样例替代。
- 未配置正式发布公钥。上位机核对资源大小和 SHA-256，设备独立验签仍为安装信任依据；不声称上位机已完成发布公钥验签。
- Windows 正式产物打开与三平台 Release 结果须在发布后核验；本文件中的隔离回归不能替代上述实机条件。
