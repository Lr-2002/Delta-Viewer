# 本地与NAS数据读取、播放恢复（1.12.7）

1.12.6 Windows实际数据窗口只读观察15秒，五路现有视频的主路5次waiting，带其余全部暂停；多次canplay后仍额外等待约0.5–0.8秒，15秒仅前进约10.6秒。证据在本机diagnostics/local-playback-1127，未上传私有路径/视频。该数据确有缓冲不足，但旧重复事件、整组暂停和恢复储备进一步放大等待，不能简单归因NAS，也未据此断言所有外接硬盘同因。

## 实现

- 目录直接read_dir，复用目录项类型识别记录，省去PowerShell预探测、exists/is_dir及每条两个清单stat；保留目录深度/数量上限、取消、认证及实际读错误。只读介质摘要不查容量，写入/导出容量保护沿用。
- 本机动作标注修订库不存在或为空时直接返回无标注，不先遍历源文件算指纹；库中有记录时仍走原指纹和修订校验。
- waiting只在原生控制器处理，已恢复或正在seek的旧事件忽略；饥饿解码器保留play意图，健康相机暂停，避免解码恢复死等。hold不再重建所有控制器；回调不能推进已冻结时间轴，暂停恢复不倒退。
- 暂停启动/恢复储备0.25秒，最多2媒体秒；连续可播时不按储备阈值反复暂停。普通模式原画质连续播放，不用高速浏览替代。
- 本机单次连续Range上限32MiB，单连接内存仍1MiB，启动64KiB块；Windows FILE_FLAG_SEQUENTIAL_SCAN允许系统顺序预读。旧video卸载主动pause/remove src/load，取消旧解码与磁盘读取。
- 长片段列表为新增控件预留一行高度，审核按钮保持可见；未削弱布局断言。
