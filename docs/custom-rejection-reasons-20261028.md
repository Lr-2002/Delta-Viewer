# 常用不通过原因（1.3.9-rc.cloudqc.7）

单条、批量、整文件夹以及云端编辑器共用 RejectionReasons。固定原因新增“数据内容缺失”。点击“添加常用原因”，输入名称后点保存或按 Enter，只创建按钮，不会提交审核。点击自定义按钮即可选用；“调整顺序”支持拖动和 Alt＋方向键，同时提供移除自定义原因。“其他原因”继续固定右下角，“恢复默认”仅恢复排序并保留自定义按钮。

自定义最多20个，每项最多40字，拒绝空白、重复、控制字符及保留前缀。仅保存当前账号在本机的配置，不宣称跨电脑同步；账号切换隔离，重启保留。v2单个localStorage文档保存自定义项和排序，并读取迁移v1既有排序，兼容写入v1顺序。保存失败保持原选项并明确提示，不能假装成功。自定义标签发送现有“其他原因：文字”协议，原生门禁不放宽；固定“数据内容缺失”增加到前后端预置白名单。移除标签不会改变已提交结论。
