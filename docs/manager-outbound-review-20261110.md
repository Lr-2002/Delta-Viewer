# D1 Manager 外发审核接入

任务中心新增“外发审核”，使用现有 Manager 登录身份读取交付平台名称含“星炬”的原始上传批次。审核员领取批次后按录制查看原始 MP4，判断有效或无效；视频由交付平台按 HTTP Range 读取，支持浏览器拖动定位，不先下载整个批次。结论、版本冲突和最终合格率由交付平台单独持久化，现有云端 QC、NAS 写回与本地任务语义不变。

Manager 按平台返回的逐录制结论展示任务状态；平台数据中心从同一持久结论生成批次有效数、无效数和最终有效率，全部录制完成前有效率保持待统计。无效原因写入结论，预设选项外的原因可由审核员保存为长期常用项。每条录制的全部原始视频（5 路或 7 路）均需就绪后才允许提交判断。

为了保留原上传清单签名与接收哈希，外发审核不改原始上传的 `description.json` 字节。平台在上传根目录生成派生副本：`<uploadRoot>/<uploadId>/outbound-review/<datasetId>/<recordingId>/description.json`。副本保留该录制原描述字段，并写入 `_outbound_review`：`schema` 为 `d1-manager.outbound-review.v1`，`status` 为 `valid` / `invalid`，无效时附 `reason`，并记录 `reviewer`、`reviewed_at`。批次数据库中的逐条结论是并发控制和统计的持久依据；描述副本是下游可读取的数据字段，列表刷新会校准副本。若同步失败，接口报错且后续列表可重试，不覆盖原始上传。

接入需要交付平台合并并部署对应接口，平台账户服务设置独立 HMAC 服务 ID/密钥，用户中心配置 `outboundReview` 的 HTTPS origin、密钥和 CA 文件，并更新用户中心服务。缺配置时界面明确显示“尚未开通”。正式接通前不可领取真实批次或提交结论；Windows 预览可用隔离夹具核对界面，但不能以隔离通过替代线上可用。

2026-11-10 只读生产核对：平台有 7 个名称含星炬的数据集，全部有原始上传和提交回执；上传清单合计 126 条录制、2114 个 MP4，视频均有接收时 hash。单 MP4 最大约 1.23 GB，所以采用受控 Range 播放。尚未领取、修改或写入任何真实结论。

平台接入代码已在 PR 中实现描述副本与数据中心统计；PR 尚未合并，服务密钥、HTTPS origin/CA、反向代理媒体票据日志策略及生产部署验证仍未完成。因此当前不能声称客户环境已开通、交付平台线上报表已生效或真实外发数据已审核。平台 PR 按仓库协作规则由另一位开发者验收合并，之后才能安排生产配置与部署验证。
