# 外发原因隔离与高倍速候选（1.11.8）

异常与无效各自显示独立原因窗口、内置词和自定义词，类别通过category保存；新版非有效decide携带reasonCategory，服务端按所属库校验。旧无分类自定义词归入原无效库，不复制到异常库；保留历史结论与旧客户端兼容。各类30个自定义项，相同文字可在两库各自保存。沿用平台窄事务reasons字段，无表结构迁移。

1.11.7实机在4倍时主相机缓存曾降至0.3秒，6/8倍其他相机缓存数十秒仍有解码等待与丢帧。新候选每次开放Range提供16MiB连续响应、滚动四个1MiB条件块，内存上限不随响应长度扩大；每块仍校验会话、领取、范围、对象身份、实际正文，取消立即停止，没有媒体缓存。整响应上限120秒，单块原25秒截止保留。

1–3倍保持原起播储备，超过3倍在开始、拖动及提高倍速时储备约3秒真实播放时间，最多额外等4秒；中断恢复储备约1.5秒真实播放时间、最多2.5秒。饥饿解码器在同伴暂停时以至多2倍恢复，整组恢复前还原用户倍速，不隐藏相机、不降画质、不反复seek。暂停／离页取消意图。此策略只能减少供给空隙和反复启停，不能越过目标机解码吞吐或网络上限；实际提升须Windows新版对照确认。
