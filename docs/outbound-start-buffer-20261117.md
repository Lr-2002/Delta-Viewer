# 外发初始缓冲候选（1.11.3）

1.11.2 的完整门禁、Windows 构建及定向原生媒体测试通过。已领取批次实测：七路约 2.1–3.6 秒就绪，短片约 11.2 秒播完 9.7 秒、长片约 31.3 秒播完 29 秒，无媒体错误，但初段仍有短暂等待。不能将首帧加载成功当作持续播放流畅。

现场首帧就绪时，高码率主相机有时仅有约 0.25 秒前向数据。候选在用户开始播放或主动定位时先积累少量前向数据，首帧仍逐路展示，使用原有“正在缓冲”反馈；额外储备等待最多两秒，正常媒体就绪条件和读取期限保持。暂停可立即取消，恢复后不会迟到自动播放。已有缓冲充分时直接开始。

持续播放中的缺数据解码器仍保持播放意图，健康相机等待，并在 canplay 恢复；连续同步不反复 seek。原生四块同时读取、范围/长度/源身份及权限校验、退出/断连取消、单批独立操作、有效/无效回执核对和自动下一条均保持。无源文件改写、媒体复制、降质或真实审核代提交。

真实视频上的临时对照显示，完成一次初始等待后可连续播放；仍以 1.11.3 编译产物和用户体验为准。浏览器新增回归覆盖首帧数据不足时暂缓开始、用户取消后不迟到启动；既有五/七路、缓冲恢复、定位、有效/无效和下一条完整流程保留。

用户验收通过前不推 Manager main/tag/Release。Windows 预览保留既有窗口、会话、草稿和原数据；正式三平台产物后续按 GitHub 发布流程构建验证。
